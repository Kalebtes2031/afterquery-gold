Add cycle controls to `for` loops so templates can alternate values without maintaining counters. Inside an active loop, `{{ loop.cycle("a", "b", ...) }}` should choose from its arguments using the current loop index, wrap when exhausted, and render an empty string with no arguments. Nested loops use the innermost loop, list and map iteration both work, and existing `loop` fields (`index`, `index0`, `revindex`, `revindex0`, `first`, `last`, `length`, `remaining`, and `depth`) stay unchanged. Calling `loop.cycle` outside a loop must fail with an error containing `inside a for loop`.

Also support `{% cycle value1, value2, ... %}`. Anonymous tags are valid only inside a loop, share that loop's cursor, advance only when a cycle tag runs, and restart from the first value for each new loop. Named groups have independent, case-sensitive cursors, may be used outside loops, and continue across separate loops during one render. Named and anonymous cycling are independent. A leading identifier followed directly by another value is a group name; a lone identifier or identifiers separated by commas are values. Both forms accept normal expressions, including numbers and filter pipelines, and emit the chosen value without added separators.

Cycles must work inside nested `if`, `with`, `filter`, and block bodies. An empty `{% cycle %}` is a parse error, while a trailing comma adds no value. Empty loops and their `else` bodies do not advance cycle state, and each new render starts fresh. Cycle-like text inside `raw` remains literal and must not interfere with a following real cycle tag. Parsing and outline output must recognize cycle tags, with outlines showing the value count and named group when present.
